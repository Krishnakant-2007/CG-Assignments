### Bonus – Resolve a Conflict Locally (Optional)

1. Create two branches that change the same line of a file.
2. Merge the first branch into `main` locally.
3. Merge the second branch → conflict appears in the terminal.
4. Open the file, resolve the markers manually, then:
   ```bash
   git add .
   git commit -m "Resolve merge conflict locally"
   ```
5. Push the result.

**Submit (optional):** Screenshot of the conflicted file and the resolution commit.
